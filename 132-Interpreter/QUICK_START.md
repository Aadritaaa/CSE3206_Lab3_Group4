# Quick Start

## C++ demo
```bash
g++ -std=c++17 cpp/*.cpp -o interpreter
./interpreter
```

## Tests
```bash
g++ -std=c++17 cpp/*.cpp tests/test_interpreter.cpp -Icpp -o interpreter_tests
./interpreter_tests
```
